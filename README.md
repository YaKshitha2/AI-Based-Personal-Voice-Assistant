# AI-Based Personal Voice Assistant

## Project Overview
This project is an AI-Based Personal Voice Assistant developed using Python. It listens to voice commands, converts speech into text, processes the commands, and responds using voice.

## Features
- Voice recognition
- Text-to-speech response
- Greeting responses
- Current time and date
- Open Google using voice commands
- Search Google using voice commands
- Tell jokes
- Exit using voice commands

## Technologies Used
- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- Jupyter Notebook

## Libraries
- speech_recognition
- pyttsx3
- datetime
- webbrowser
- random
- urllib.parse

## How to Run
1. Install the required Python libraries.
2. Open the Jupyter Notebook.
3. Run the notebook cells in order.
4. Allow microphone access.
5. Speak commands to interact with the assistant.
6. Say "Stop" or "Exit" to close the assistant.

## Example Voice Commands
- Hello
- What is your name?
- What is the time?
- What is today's date?
- Open Google
- Search Python tutorials
- Tell me a joke
- Stop
